# 登塔者 · Climb Tower

一款「反向俄罗斯方块」演出小游戏：**方块从头顶落下，你要在方块之间攀爬，抵达舞台顶端**。
由 Python + pygame 实现，内置剧情系统、视觉特效（VFX）、存档与可视化演出编辑器。

对应 PRD：`../PRD.md`，基础规则 `../rule/base.md`，编辑器规则 `../rule/editor.md`，扩展规则 `../rule/extension.md`。

## 运行

```bash
# 依赖：Python 3.9+（本项目在 3.13 + pygame 2.6 验证）
pip install pygame
python main.py
```

Windows 可直接双击 `启动游戏.bat`。

## 玩法（对应 rule/base.md）

- 小人站在 `10格宽 × 20格高` 的舞台底部（尺寸可由创作者修改）。
- **方块会跟随玩家所在的位置，直到开始下落**：倒计时期间方块悬浮在头顶并跟着你走，你想让它落在哪一列，就站在哪一列。
- **每次下落之前有 2 ~ 9.9 秒倒计时**（区间可调，满足“不到 10 秒、最少 2 秒”）。
- 倒计时归零后台块开始下落——此时它不再跟踪你，赶紧躲开：
  - **被下落的方块命中** → 演出立即终止；
  - **被困在封闭空间内**（墙壁、边界也算）→ 演出立即终止；
  - 失败文本由剧情作者定义，未定义时显示 **“败北”**。
- **到达舞台顶部即胜利**（默认目标为第 0 行，可由创作者改为其他行 / 坚持时间 / 承受块数 / 完全交给剧本）。
- **可选：多个方块同时在场**（`blocks.concurrent`，默认 1 即经典的一块一块来）。设成 3 时，舞台上会同时出现三块：**最新那块跟着你走**，先出现的块停在它们出现时的那一列继续倒计时，然后各自下落、各自固化。
- **催落**：倒计时期间按 **↓ / S** 可以让那块**立刻开始下落**（跳过剩余倒计时，但下落速度不变）。不想等的时候用它抢时间，也可以主动给自己造落脚点。创作者可在「玩法」页用「玩家可催落方块」开关禁用它（`blocks.quick_drop`）。
- **可选：填满一行即消行**（`blocks.line_clear`）。某一行的每一格都填上后，整行消失、上方整体下落一格。**默认关闭**——攀爬类演出开着它，辛苦搭的台阶会被抽走；创作者可按需开启，也可以直接把它设为胜利条件（见下）。消行时小人若被下移的地形挤住会自动顶出去。

### 操作

| 按键 | 作用 |
| --- | --- |
| ← → 或 A D | 移动小人（手动瞄准模式：← → 控制方块，A D 控制小人） |
| **↓ / S** | **催落**：无视剩余倒计时，让头顶正在瞄准的那块立刻开始下落（下落速度不变） |
| 空格 / ↑ / W | 跳跃（可跳上约 2 格高的方块，走路可自动跨 1 格台阶） |
| **X**（或 Z） | 旋转当前方块：瞄准与下落途中都可用，**固化进舞台之后不能再改变** |
| 空格 / 回车 / 点击 / 方向键 | 推进对白 |
| R | 重新开始本场演出 |
| P | 暂停 |
| Esc | 返回 |

> 带有 `mode: blocking` 剧本的演出（如默认的开场白）会**暂停世界**等你确认，
> 此时按空格、点击鼠标，或按方向键都能继续；底部会显示「空格 / 点击 继续」的闪烁提示。
>
> 旋转采用**底边对齐 + 踢墙**：贴着墙或贴着已有方块时会自动左右挪一格（必要时上抬），
> 实在放不下就不转，方块保持原样。

## 内置内容

| 演出 | 说明 |
| --- | --- |
| 教学：矮舞台 | 8×12 小台子，目标第 2 行，熟悉“引块—躲开—攀爬”循环 |
| 初次登场 | 标准 10×20 舞台，抵达第 0 行（PRD 默认规则） |
| 高塔竞演 | 12×22、手动瞄准、加速下落 |
| 被诅咒的第三幕 | 胜负完全由剧本决定（`goal.type = none`），演示 on_row / drop / vfx / win 指令 |
| 形状与事件示例 | 演示自定义形状（十字 / 阶梯）、`drop` 定点投放与 7 条自定义事件 |
| 三块齐落 | `concurrent: 3`——舞台上同时存在三个方块，一块瞄准、两块下落 |
| 清道夫 | 开启消行（`line_clear`）：底部两行各差最右一格，把长条竖着塞进去就能一次消两行、直接通关 |

## 编辑器（对应 rule/editor.md）

菜单 → **打开编辑器**（或 F2）。六个分页：

1. **基本**：舞台宽高、失败文本（整体 + 按“命中/封困/无法上行/填满”分别自定义）、地形绘制（调色板点选后在画布上拖动，右键擦除，Shift+点击设置出生列）。
2. **玩法**：瞄准方式（跟随小人 / 玩家控制 / 随机落点）、倒计时上下限、下落间隔、加速系数、方块池（含自定义形状）、**同时在场的方块数（1~6）与多块生成间隔**、**填满一行即消行**、小人的速度/跳跃/重力/攀爬、开演音乐。
3. **形状**：**自定义方块形状**——内置 7 种只读（可「复制」后再改），自定义形状可在 6×6 网格里点出任意造型、改名字与颜色（14 色），系统自动生成 4 个朝向。
4. **目标/失败**：胜利条件类型与参数（抵达行 / 坚持时间 / 承受块数 / **消除行数**）；四类失败条件开关。
5. **VFX**：11 种特效开关（落雨、飘雪、火星、闪光、震屏、网格脉冲、暗角、扫描线、故障、星空、浓雾）。
6. **事件/剧本**：**无限条事件**，每条可自选触发时机与参数，剧本可选“自动推进”或“等待玩家确认”；可直接载入 `content/stories/` 里的剧情文件。

`Ctrl+S` 保存到 `content/levels/*.json`，`Ctrl+E` 随时试演；顶栏「导入 / 导出」可与其他创作者交换演出文件。

### 自定义形状

- 形状以格子坐标存储：`"cells": [[1,0],[0,1],[1,1],[2,1],[1,2]]`，也支持 `"010/111"` 文本写法。
- 进池：在「玩法」页把形状 id 勾进方块池；或直接由剧本 `drop <形状id> <列>` 投放。
- 自定义形状与内置形状一样可被 **X 键旋转**（固化后不可改），并按同一套底边对齐 + 踢墙规则落位。
- 示例演出 `shape_demo`（“形状与事件示例”）里就用了「十字」和「阶梯」两个自定义形状。

### 事件与触发时机

一条事件 = **触发时机 +（可选）参数 + 演出方式 + 剧本**。数量不限，同个时机也可以挂多条。

| 触发时机 | 含义 | 参数 |
| --- | --- | --- |
| `on_line_clear` | 消行时（本次至少消掉 N 行；不填 = 每次都触发） | 行数 |
| `on_clear_count` | 累计消除行数达到 N | 行数 |
| `on_start` | 开演时 | — |
| `on_spawn` | 方块出现时 | — |
| `on_aim_end` | 倒计时结束、开始下落时 | — |
| `on_lock` | 方块固化后 | — |
| `on_row` | 小人抵达第 N 行（含更高） | 行号 |
| `on_height` | 小人最高抵达过第 N 行 | 行号 |
| `on_time` | 开演后第 N 秒 | 秒 |
| `on_lock_count` | 已固化 N 块 | 块数 |
| `on_piece` | 出现某个形状时 | 形状 id |
| `on_key` | 玩家按下某键时 | 按键名（`x` / `space` / `up` …） |
| `on_win` / `on_lose` | 胜利 / 失败时 | — |

- 每条事件可勾选「只触发一次」（默认）；取消勾选则该时机每次满足都会再演一遍。
- 旧版字典写法（`"events": {"on_start": "...", "on_row:3": {...}}`）仍会被自动识别并转换。

### 剧本格式（对应 rule/editor.md）

```
角色名字: 语句。 // 对话
:语句文本。 // 旁白
角色名字：语句。 \ 指令 // 注释
```

- 冒号中英文皆可；`//` 后为注释；`\` 后为指令，多条指令用 `;` 分隔。
- 全角、半角均可；空角色名即旁白。

### 指令（对应 rule/extension.md 的“脚本可自定义的内容”）

| 指令 | 作用 |
| --- | --- |
| `win` | 直接胜利 |
| `lose [文本]` | 直接失败（可自定义失败文本） |
| `drop [n]` | 立即让 n 个方块下落（跳过倒计时） |
| `drop <形状> [列] [朝向] [块数]` | **指定形状与落点**投放：列可写数字、`player`（小人所在列）或 `random` |
| `vfx <名> on/off` | 激活 / 解除 VFX |
| `sfx <名> [音量]` | **播放音效**（内置名 / 中文别名 / `content/audio/` 下的文件名） |
| `bgm <名> [音量]` | **循环播放背景音乐**；`bgm off` 停止 |
| `vol <0-100>` | 全局音量 |
| `mute` | 静音 / 恢复 |
| `clear` | 文本消除（清空对白） |
| `reset` | 重置舞台 |
| `quit` | 关闭游戏 |
| `wipe` | 删除存档 |
| `delay <毫秒>` | 之后的指令延迟执行 |
| `shake <强度>` | 一次性震屏 |

指令区里 `\` 与 `;` 都可作分隔符，例如 `主角: 稳住！ \ sfx 铃声; delay 400 \ win`。

`drop` 的几种写法：

```
drop                   立即落 1 块（随机形状）
drop 3                 立即落 3 块
drop T                 立即落一块 T（沿用当前瞄准列）
drop T 4               一块 T 落在第 4 列
drop T player 1 2      两块 T，落在小人所在列、朝向 1
drop cross 3           落一块自定义形状「cross」到第 3 列
drop T 4 slow          跳过倒计时，但按正常速度落下（能看清过程）
```

> `drop` 默认**瞬间落到底**；带上 `slow`（或 `慢`）就只跳过倒计时、保留下落过程——
> 多块同台时用它，能看到几块一起往下掉。

## 音频

全部为**内置合成音**，无需外部资源；也可把自己的 `.ogg/.wav` 放进 `content/audio/`，
之后用文件名（不含扩展名）直接在剧本里播放。

- **音效**（`sfx` 指令，支持中文别名）：落块闷响 `thud`、方块固化 `lock`、跳跃 `jump`、
  落地 `land`、脚步 `step`、铃声 `bell`、清音 `chime`、金币 `coin`、鼓点 `drum`、铜锣 `gong`、
  雷声 `thunder`、风声 `whoosh`、蜂鸣 `buzz`、心跳 `heartbeat`、掌声 `applause`、故障 `glitch`、
  星光 `sparkle`、开门 `door`、警报 `alarm`、滴答 `tick`、点击 `click`、界面提示 `ui`、
  胜利 `win`、失败 `lose`
- **背景音乐**（`bgm` 指令 / 关卡配置）：平静 `calm`、紧张 `tense`、诡异 `ominous`、
  圆舞曲 `waltz`、进行曲 `march`
- **关卡配置**：`"audio": { "bgm": "calm", "volume": 55 }`，开演自动循环播放，退场自动停止
- **编辑器**：「玩法」分页可设置开演音乐与音量（试听/停止）；「事件/剧本」分页底部有音效
  选择器，可试听并一键把 `sfx xxx` / `bgm xxx` 插入当前剧本行
- **菜单**：右侧「音量」步进器实时调节并写入存档（0 = 静音）

## 存档

- `saves/save.json`：每场演出的通关次数、最高抵达行、挑战次数、已读剧情。
- 菜单里可一键删除存档；剧本指令 `wipe` 亦可。

## 自定义关卡（JSON）

```jsonc
{
  "id": "my_show", "title": "我的演出", "order": 1,
  "stage": { "width": 10, "height": 20 },
  "blocks": { "pool": ["I","O","T","cross"], "allow_rotation": true,
              "player_rotate": true, "hover": "follow", "aim_time": [2.0, 9.9],
              "concurrent": 3, "spawn_gap": 0.8,   // 同时在场 3 块，间隔 0.8 秒补一块
              "quick_drop": true,                   // 玩家可用 ↓ / S 催落（无视倒计时）
              "line_clear": false,                  // 填满一行即消行（默认关）
              "fall_interval": 0.3, "fall_interval_min": 0.1, "ramp": 0.985 },
  "player": { "move_speed": 6.4, "jump_height": 2.6, "gravity": 34.0, "climb": 1 },
  "goal": { "type": "reach_row", "row": 0 },       // 或 survive / lock_count / clear_lines / none
                                                   // clear_lines 用 "clear": 6 表示消 6 行
  "fail": { "text": "败北", "texts": { "crush": "……" },
            "crush": true, "buried": true, "stuck": false, "overflow": false },
  "vfx": ["rain"],
  "audio": { "bgm": "calm", "volume": 55 },
  "shapes": [                                      // 自定义形状（可任意多个）
    { "id": "cross", "name": "十字", "color": 9,
      "cells": [[1,0],[0,1],[1,1],[2,1],[1,2]] }
  ],
  "events": [                                      // 事件列表（可任意多条）
    { "trigger": "on_start", "mode": "blocking", "script": "司仪: 开场。" },
    { "trigger": "on_time", "param": 6, "mode": "ambient",
      "script": "司仪: 送一块。 \\ drop cross 4" },
    { "trigger": "on_lock_count", "param": 3, "once": true, "script": "……" }
  ],
  "terrain": ["..........", "..."]                  // 每行一个字符串：. 空 # 墙 1-7 方块色
}
```

放入 `content/levels/` 即会出现在菜单列表（`order` 决定排序）。

### 导入 / 导出

- **编辑器顶栏「导出」**：把当前演出（含自定义形状、事件、地形）存成单个 `.json`。
- **编辑器顶栏「导入」**：读取一个演出 JSON；若是 `{"levels": [...]}` 打包文件则取第一份。
- **菜单「导入演出」**：选择 JSON 后直接安装到 `content/levels/` 并刷新列表。
- 没有文件对话框时（极简环境）自动降级：导出到 `build/export/`，导入读取 `build/import/` 下最新的 `.json`。
