# 登塔者 · Climb Tower

一款「反向俄罗斯方块」演出小游戏：**方块从头顶落下，你要在方块之间攀爬，抵达舞台顶端**。
由 Python + pygame 实现，内置剧情系统、视觉特效（VFX）、存档与可视化演出编辑器。

对应 PRD：`../PRD.md`，基础规则 `../rule/base.md`，编辑器规则 `../rule/editor.md`，扩展规则 `../rule/extension.md`。

## 运行

```bash
# 依赖：Python 3.9+（本项目在 3.13 + pygame 2.6 验证）
pip install pygame
python main.py
```

Windows 可直接双击 `启动游戏.bat`。

## 玩法（对应 rule/base.md）

- 小人站在 `10格宽 × 20格高` 的舞台底部（尺寸可由创作者修改）。
- **方块会跟随玩家所在的位置，直到开始下落**：倒计时期间方块悬浮在头顶并跟着你走，你想让它落在哪一列，就站在哪一列。
- **每次下落之前有 2 ~ 9.9 秒倒计时**（区间可调，满足“不到 10 秒、最少 2 秒”）。
- 倒计时归零后台块开始下落——此时它不再跟踪你，赶紧躲开：
  - **被下落的方块命中** → 演出立即终止；
  - **被困在封闭空间内**（墙壁、边界也算）→ 演出立即终止；
  - 失败文本由剧情作者定义，未定义时显示 **“败北”**。
- **到达舞台顶部即胜利**（默认目标为第 0 行，可由创作者改为其他行 / 坚持时间 / 承受块数 / 完全交给剧本）。

### 操作

| 按键 | 作用 |
| --- | --- |
| ← → 或 A D | 移动小人（手动瞄准模式：← → 控制方块，A D 控制小人） |
| 空格 / ↑ / W | 跳跃（可跳上约 2 格高的方块，走路可自动跨 1 格台阶） |
| **X**（或 Z） | 旋转当前方块：瞄准与下落途中都可用，**固化进舞台之后不能再改变** |
| 空格 / 回车 / 点击 / 方向键 | 推进对白 |
| R | 重新开始本场演出 |
| P | 暂停 |
| Esc | 返回 |

> 带有 `mode: blocking` 剧本的演出（如默认的开场白）会**暂停世界**等你确认，
> 此时按空格、点击鼠标，或按方向键都能继续；底部会显示「空格 / 点击 继续」的闪烁提示。
>
> 旋转采用**底边对齐 + 踢墙**：贴着墙或贴着已有方块时会自动左右挪一格（必要时上抬），
> 实在放不下就不转，方块保持原样。

## 内置内容

| 演出 | 说明 |
| --- | --- |
| 教学：矮舞台 | 8×12 小台子，目标第 2 行，熟悉“引块—躲开—攀爬”循环 |
| 初次登场 | 标准 10×20 舞台，抵达第 0 行（PRD 默认规则） |
| 高塔竞演 | 12×22、手动瞄准、加速下落 |
| 被诅咒的第三幕 | 胜负完全由剧本决定（`goal.type = none`），演示 on_row / drop / vfx / win 指令 |

特色玩法预设（菜单里一键叠加）：`雨夜突袭`、`我来瞄准`、`停电剧场`。

## 编辑器（对应 rule/editor.md）

菜单 → **打开编辑器**（或 F2）。五个分页：

1. **基本**：舞台宽高、失败文本（整体 + 按“命中/封困/无法上行/填满”分别自定义）、地形绘制（调色板点选后在画布上拖动，右键擦除，Shift+点击设置出生列）。
2. **玩法**：瞄准方式（跟随小人 / 玩家控制 / 随机落点）、倒计时上下限、下落间隔、加速系数、方块池、小人的速度/跳跃/重力/攀爬。
3. **目标/失败**：胜利条件类型与参数；四类失败条件开关。
4. **VFX**：11 种特效开关（落雨、飘雪、火星、闪光、震屏、网格脉冲、暗角、扫描线、故障、星空、浓雾）。
5. **事件/剧本**：为 `开演时 / 方块出现 / 倒计时结束 / 方块固化 / 抵达第 N 行 / 胜利 / 失败` 编写剧本，可选“自动推进”或“等待玩家确认”；可直接载入 `content/stories/` 里的剧情文件。

`Ctrl+S` 保存到 `content/levels/*.json`，`Ctrl+E` 随时试演。

### 剧本格式（对应 rule/editor.md）

```
角色名字: 语句。 // 对话
:语句文本。 // 旁白
角色名字：语句。 \ 指令 // 注释
```

- 冒号中英文皆可；`//` 后为注释；`\` 后为指令，多条指令用 `;` 分隔。
- 全角、半角均可；空角色名即旁白。

### 指令（对应 rule/extension.md 的“脚本可自定义的内容”）

| 指令 | 作用 |
| --- | --- |
| `win` | 直接胜利 |
| `lose [文本]` | 直接失败（可自定义失败文本） |
| `drop [n]` | 立即让 n 个方块下落（跳过倒计时） |
| `vfx <名> on/off` | 激活 / 解除 VFX |
| `sfx <名> [音量]` | **播放音效**（内置名 / 中文别名 / `content/audio/` 下的文件名） |
| `bgm <名> [音量]` | **循环播放背景音乐**；`bgm off` 停止 |
| `vol <0-100>` | 全局音量 |
| `mute` | 静音 / 恢复 |
| `clear` | 文本消除（清空对白） |
| `reset` | 重置舞台 |
| `quit` | 关闭游戏 |
| `wipe` | 删除存档 |
| `delay <毫秒>` | 之后的指令延迟执行 |
| `shake <强度>` | 一次性震屏 |

指令区里 `\` 与 `;` 都可作分隔符，例如 `主角: 稳住！ \ sfx 铃声; delay 400 \ win`。

## 音频

全部为**内置合成音**，无需外部资源；也可把自己的 `.ogg/.wav` 放进 `content/audio/`，
之后用文件名（不含扩展名）直接在剧本里播放。

- **音效**（`sfx` 指令，支持中文别名）：落块闷响 `thud`、方块固化 `lock`、跳跃 `jump`、
  落地 `land`、脚步 `step`、铃声 `bell`、清音 `chime`、金币 `coin`、鼓点 `drum`、铜锣 `gong`、
  雷声 `thunder`、风声 `whoosh`、蜂鸣 `buzz`、心跳 `heartbeat`、掌声 `applause`、故障 `glitch`、
  星光 `sparkle`、开门 `door`、警报 `alarm`、滴答 `tick`、点击 `click`、界面提示 `ui`、
  胜利 `win`、失败 `lose`
- **背景音乐**（`bgm` 指令 / 关卡配置）：平静 `calm`、紧张 `tense`、诡异 `ominous`、
  圆舞曲 `waltz`、进行曲 `march`
- **关卡配置**：`"audio": { "bgm": "calm", "volume": 55 }`，开演自动循环播放，退场自动停止
- **编辑器**：「玩法」分页可设置开演音乐与音量（试听/停止）；「事件/剧本」分页底部有音效
  选择器，可试听并一键把 `sfx xxx` / `bgm xxx` 插入当前剧本行
- **菜单**：右侧「音量」步进器实时调节并写入存档（0 = 静音）

## 存档

- `saves/save.json`：每场演出的通关次数、最高抵达行、挑战次数、已读剧情。
- 菜单里可一键删除存档；剧本指令 `wipe` 亦可。

## 自定义关卡（JSON）

```jsonc
{
  "id": "my_show", "title": "我的演出", "order": 1,
  "stage": { "width": 10, "height": 20 },
  "blocks": { "pool": ["I","O","T","S","Z","J","L"], "allow_rotation": true,
              "hover": "follow", "aim_time": [2.0, 9.9],
              "fall_interval": 0.3, "fall_interval_min": 0.1, "ramp": 0.985 },
  "player": { "move_speed": 6.4, "jump_height": 2.6, "gravity": 34.0, "climb": 1 },
  "goal": { "type": "reach_row", "row": 0 },       // 或 survive / lock_count / none
  "fail": { "text": "败北", "texts": { "crush": "……" },
            "crush": true, "buried": true, "stuck": false, "overflow": false },
  "vfx": ["rain"],
  "audio": { "bgm": "calm", "volume": 55 },
  "events": { "on_start": { "mode": "blocking", "script": ":……" } },
  "terrain": ["..........", "..."]                  // 每行一个字符串：. 空 # 墙 1-7 方块色
}
```

放入 `content/levels/` 即会出现在菜单列表（`order` 决定排序）。

